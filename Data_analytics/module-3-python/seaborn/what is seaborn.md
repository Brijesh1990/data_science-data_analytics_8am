# what is seaborn ? 
1. seabron is an external library create a graph and plot data on graph
2. seaborn used with numpy | pandas and matplotlib 
3. seaborn provides to plot a data on graph using its dataset
4. seaborn base used in data science | machine learning for plot a data on graph 
5. seaborn is used to create a dataset on graph and also visualized data on graph 
6. seaborn used to show graph via matplotlib 
7. seabron is a third party library to visualized data on graph 
8. seaborn is install and used in python 
9. seaborn is used to plot numerical data on graph 
10. seaborn is used to  Statistical data visualization
11. seaborn is used python > 3.6.0 version to visualized data

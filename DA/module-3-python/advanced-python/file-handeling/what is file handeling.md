# what is file handling in python ?

   1. file handling is used to handel any file inside of python 
   2. file handling is used to open file | read file | write on external file inside of python 
   3. file handling is used to removed file using os module in python 
   4. file handling provides some inbuilt function to handle file 


# file handling function 

  1. open() : open a file 
  2. read() : read a file 
  3. write() : write on file 
  4. append(): append on any file
  5. close(): close a file 
  6. remove(): delete any file 
  7. with() : with is used to open or close any file with method

# file handling mode of file


  1. r: read only if file does not available not create new file
  2. r+: read/write only if file does not available not create new file
  3. w: write only if file does not available  create new file
  4. w+: read/write only if file does not available  create new file 
  5. a: append only if file does not available  create new file
  6. a+: read/write and append only if file does not available  create new file

# what is python module list out all types of module ?

1. A Python module is a file containing Python code, such as functions, classes, and variables, that can be imported into other Python programs.
2. A module is save with .py or a small peace of .py file i.e called module
3. A module is also imported into other python programmes 
4. A module is re-used one module to another by **import** keyword


## Types of Python modules:

- Built-in modules or pre defined module: Provided by Python itself, such as `sys`, `os`, `math`, and `datetime`.

- Standard library modules: Included with Python installation, such as `json`, `re`, `csv`, `random`, and `collections`.


- Third-party modules: Installed from external sources like PyPI, for example `numpy`, `pandas`, `requests`, and `matplotlib`.
- User-defined modules: Created by developers in their own `.py` files for reuse in projects.

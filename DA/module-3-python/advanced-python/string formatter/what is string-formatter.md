# what is string-formatter ? 

  1. string formatter print any string in any formate 
  2. string formatter print a number or decimal inside of string using string formatter

  3. string formatter denoted by **f"my name is brijesh"** 

  4. string formatter is used some placeholder to print a number inside of string 


  ``` 
  name='brijesh'
  age=35
  salary=115000

  print("my name is :\n",name,"my age is :\n",age,"my salary is :",salary)

  ```

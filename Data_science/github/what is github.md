
# create an account on github 

  **what is github**

  1. github is an microsoft product 
  2. github is open source
  3. github is used to stored your all file . folder and data on its server and shared by anyone
  4. github create an repository to stored all data 


  **steps to used github**

  1. create an account on github 

     https://github.com/

  2. login with your account in github 

  3. create an repository

  4. upload all your data on github drag and drop

     or
  
  5. using command to upload data 

  ```
  git init
  
  git add .
  
  git commit -m "first commit"
  
  git remote add origin https://github.com/Brijesh1990/data_science-data_analytics_8am.git
  
  git push -u origin main

  ```
